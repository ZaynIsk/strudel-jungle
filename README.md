# strudel-jungle

**Sayang Track** — atmospheric jungle live-coded in [Strudel](https://strudel.cc): rolling breaks, Rhodes, strings, trumpet and birdsong, with an audio-reactive circular visual.

## Play

Open [strudel.cc](https://strudel.cc), paste in [`track.js`](track.js), press **Ctrl/Cmd + Enter**.

## Edit locally

Run `npm run dev`, then swap the `samples('github:…')` line in `track.js` for the commented `localhost` one.
Run `npm run map` before committing new samples.
