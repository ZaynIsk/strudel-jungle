Drop your vocal sample(s) here (.wav, .mp3, .ogg, .flac, .m4a or .aiff).

- First file (alphabetically) is `vocals:0`, the next `vocals:1`, and so on.
  Prefix names with numbers to control the order: `00_hook.wav`, `01_adlib.wav`.
- With `npm run dev` running, just re-evaluate in strudel.cc – no restart needed.
- Before pushing to GitHub, run `npm run map` so `strudel.json` includes them.
- Only commit vocals you own or have the rights to share.
